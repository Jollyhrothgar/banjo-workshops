# Banjo workshops

Restored recordings of banjo workshops, served with GitHub Pages at
`https://mikebeaumier.com/banjo-workshops/<folder>/`. Each folder is a
self-contained static site with no build step.

| Folder | Workshop |
| --- | --- |
| [`bill-keith-banjo-lounge-2006/`](bill-keith-banjo-lounge-2006/) | Bill Keith's online workshop at the Banjo Lounge, October 17, 2006: audio with synchronized slides, whiteboard and chat, plus handouts |

`.nojekyll` tells GitHub Pages to serve the files exactly as they are.
